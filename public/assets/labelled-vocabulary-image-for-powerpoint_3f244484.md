# Labelled Vocabulary Image for PowerPoint

## What this makes

This prompt creates one striking 16:9 image for a PowerPoint vocabulary slide. It helps secondary English learners connect target words with clear visual examples in one coherent scene.

## What you need

- A list of **three to six vocabulary items** that you want to teach.
- A broad visual theme that connects the words, such as **urban development**, **sustainable fashion**, **school life**, or **travel**.
- Your learners’ year group or English level.
- An optional example image or preferred visual style, if you want the result to match an existing presentation.

| Setting | Suggested choice |
|---|---|
| Number of target items | 3–6 |
| Slide format | 16:9 landscape |
| Labels | UPPERCASE, bold, high-contrast sans-serif text |
| Language | British English unless you change it |

## How to use it

1. Prepare your vocabulary list and choose a theme that makes the meanings easy to show visually.
2. Open your chosen AI assistant. Attach a reference image if you have one.
3. Copy the whole prompt below. Change only the words in **[SQUARE BRACKETS]**.
4. Send the prompt and read through the image before using it with students.

## Copy-and-paste prompt

```text
You are helping me create a labelled vocabulary image for a PowerPoint slide for [YEAR GROUP / ENGLISH LEVEL] learners.

### Materials
I have provided: [LIST THE TARGET WORDS, THE OVERALL THEME, AND ANY REFERENCE IMAGE OR STYLE REQUEST].

### Task
Create one visually memorable, landscape 16:9 image that teaches the following vocabulary through visual context:

[TARGET WORD 1]
[TARGET WORD 2]
[TARGET WORD 3]
[TARGET WORD 4]
[TARGET WORD 5]
[ADD OR REMOVE WORDS AS NEEDED]

Use the theme: [THEME].

Make the picture a **single continuous scene**, not a collage, comic strip, grid, or set of separate panels. The areas representing the vocabulary items should flow naturally into one another through shared setting, lighting, people, architecture, furniture, landscape, or other suitable connecting details. Do not use hard borders, dividers, or grid lines.

For each target word, create one distinct, meaningful visual area or action that clearly illustrates its meaning. Position the areas across the scene so that they are easy to distinguish, while keeping the overall image natural and coherent.

### Requirements
1. Add a bold, high-contrast, sans-serif label with the exact spelling of each target word. Use uppercase labels unless a different style is requested.
2. Place every label close to the object, person, action, or area it describes. Use a thin pointer line or arrow where the target could be unclear.
3. Put labels in open space, above or beside their targets. Do not cover faces, bodies, key objects, or important parts of the scene.
4. Do not place any label in the bottom quarter of the image, as this area may be obscured when projected or cropped in PowerPoint.
5. Make the target words the only important text. Any other readable text, including notices, screens, labels, menus, price tags, and signs, must be accurate English and must not distract from the vocabulary labels.
6. Ensure that each word is illustrated by a different and accurate visual example. Do not repeat a distinctive prop or visual device in more than one area.
7. Use an age-appropriate, professional visual style suitable for a classroom presentation. Make sure the scene has strong contrast and enough visual detail for projection.

### Output
Provide one finished 16:9 landscape image ready to insert into PowerPoint. Use British English spelling and punctuation in all labels and any readable text, unless I specify another variety.

### Check before delivery
Check that:
- every target word is included exactly once and is spelled correctly;
- every label clearly points to a relevant visual example of that word;
- the image is one seamless scene with no panels, dividers, or grid lines;
- labels are readable, unobstructed, and positioned above the bottom quarter of the image;
- the visual examples accurately show the intended meanings and are suitable for [YEAR GROUP / ENGLISH LEVEL] learners;
- no unrelated or incorrect readable text distracts from the target vocabulary.

If you cannot create an image directly, provide a detailed image-generation prompt that follows all of the requirements above. Ask one focused question only if the target vocabulary list or the overall theme is missing. Otherwise, proceed.
```

## Before you use the result with students

Check that every target word appears once, is spelled correctly, and points to a visual example that genuinely conveys its meaning. Project or preview the image at slide size to make sure the labels remain easy to read and that none is too close to the bottom edge.

| Check | What to look for |
|---|---|
| Meaning | Each visual example communicates the intended meaning, not merely an associated topic. |
| Labelling | Every label is legible, correctly spelled, and linked unambiguously to its target. |
| Layout | The scene looks like one image rather than several images pasted together. |
| Classroom use | The image is age-appropriate, uncluttered, and readable on a projected slide. |

## If your AI assistant cannot make the file you want

Ask it to provide a detailed image prompt instead. You can paste that prompt into an image-making AI tool, then insert the resulting image into your PowerPoint slide.

## What you can change

You can safely change the **year group or English level**, **number of target words**, **visual theme**, and **visual style**. Keep the single-scene layout, accurate visual meanings, clear English labels, and label-placement rules unchanged because these features make the slide easier for students to understand.

> **Example theme:** A modern metropolis can naturally illustrate *commercialised*, *materialistic*, *prospects*, *transformation*, and *metropolis* through advertising districts, luxury shoppers, a career-focused professional, urban redevelopment, and a panoramic city skyline.
