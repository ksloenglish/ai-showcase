# DSE English Vocabulary Glossary from a Reading Passage

## What this makes

This prompt creates a completed glossary for DSE English reading passages for Hong Kong Chinese-speaking students. It gives students line numbers, vocabulary items, parts of speech, verified CEFR levels, Traditional Chinese meanings, and English example sentences when the template includes an Example column.

## What you need

- A reading passage in PDF, Word, or pasted-text form. A clear PDF is especially useful when the passage has printed line numbers.
- An editable Word glossary template if you want a particular layout. If you do not attach one, ask for a simple DSE-style Word glossary with an Example column.
- A complete A1–C2 CEFR reference list if you need exact CEFR labels. It should include the word and part of speech for each entry.
- The learner group and language variety. The prompt below uses British English and is written for Hong Kong senior-secondary students.

## How to use it

1. Prepare the passage, template, and CEFR reference list where available.
2. Open your chosen AI assistant and attach or paste the material.
3. Copy the whole prompt below. Change only the words in `[SQUARE BRACKETS]` if needed.
4. Send the prompt. Read through the finished glossary before giving it to students.

## Copy-and-paste prompt

```text
You are helping me create a completed vocabulary glossary for [HONG KONG SENIOR-SECONDARY / DSE ENGLISH STUDENTS].

### Materials
I have provided:
- [READING PASSAGE: PDF, WORD FILE, IMAGE, OR PASTED TEXT]
- [EDITABLE WORD GLOSSARY TEMPLATE, IF ATTACHED]
- [COMPLETE A1–C2 CEFR WORD LIST WITH PARTS OF SPEECH, IF ATTACHED]

Use only information that you can read from the provided materials. Do not invent, alter, or silently omit source content. Use British English spelling and punctuation in all original English writing.

### Task
Create a complete, accurate, and well-formatted glossary for every text in the supplied reading passage. If a Word template is attached, use its layout and column headings. If no template is attached, create an editable DSE-style Word glossary with the columns Line, Word / Phrase, POS, CEFR, Definition, and Example.

Create a separate table headed TEXT 1, TEXT 2, and so on for every text in the passage. Remove any empty placeholder rows from the template before adding the completed entries.

### Requirements
1. Scan each title before reading its body text. Include every C1/C2 title item that qualifies under the CEFR rules below. Also include a non-list single word that is central to the text’s topic and any opaque or idiomatic multi-word title phrase. Use “title” in the Line column for each title entry. List title entries from left to right.
2. Identify the lemma and the part of speech used in the passage before checking CEFR. Include every item that is C1 or C2 in the supplied A1–C2 reference. Match both word and part of speech exactly. Do not give a CEFR level to a word merely because a related word or a different part of speech appears on the list.
3. Present inflected forms in their base form without changing the part of speech. For example, change plural nouns and inflected verbs to their base forms, but do not change an adverb into an adjective or a noun into a verb. If a less common spelling variant appears, use the standard spelling followed by the source spelling in brackets only after both spellings have been checked in a standard dictionary.
4. Leave the CEFR column blank only when the item is confirmed absent from the supplied reference in that exact word form or same-part-of-speech lemma. Never guess, estimate, or infer a CEFR level from a related word.
5. Also include a non-list word or phrase when it is clearly advanced, opaque, idiomatic, topic-specific, or central to the topic. Include a topic word or its direct derivative if it appears repeatedly in the body text. Exclude transparent derivatives of A1–B1 words unless their spelling or meaning has changed enough to create a real comprehension barrier. Always include derivatives of B2, C1, and C2 words. Ignore proper nouns.
6. Include opaque idiomatic phrases and phrasal verbs as one entry. Categorise every multi-word item as “phr”, regardless of its grammatical function.
7. List entries strictly in the order they appear. On the same line, use left-to-right order. Apply this rule to all items, including a mixture of CEFR-list and non-list vocabulary. Include a word or phrase once only across the full glossary. When an item reappears in a later text, retain only its first occurrence.
8. For a normal passage, use its printed line numbers. Use the printed margin markers as anchors: count from the nearest lower marker and check the result against the next higher marker. Count printed text only. Do not count blank lines, titles, or headers. Count subheadings and printed comment labels such as “Posted by” only when they occupy a printed line. Paragraph numbers are part of their line and do not start another line. For a phrase that crosses a line break, show both line numbers, for example “49–50”. Use the first occurrence of an item, including an inflected or morphological form, whenever it occurs more than once.
9. If a text is laid out as a table, use the named row as the Line entry. Read the table row by row from top to bottom and columns from left to right. Do not assign items to a shared column heading or group them by column.
10. Use only these POS labels: v, n, adj, adv, prep, conj, phr. Do not add full stops after them.
11. Write a concise Traditional Chinese definition that fits the source context. Use as few words as possible, separate alternatives with a Chinese semicolon (；), and use “...” for a person or thing where helpful.
12. Add an original example sentence only when the template has an Example column. Each example must be 8–12 words long, suitable for B2 learners, natural, grammatically correct, and clearly show the target word’s meaning and part of speech. Do not copy an example from the source passage.
13. Keep the template’s key layout, including its header, explanatory note, column headings, fonts, italics, and student-information fields. Italicise the Word / Phrase column when the template does so. Keep tables readable and add pages or rows where needed.

### Output
Provide a completed editable Word document. For each item, give the line identifier, word or phrase, POS, CEFR level where verified, Traditional Chinese definition, and, only if required by the template, an English example sentence.

If you cannot create or edit a Word document, say so before proceeding. Then provide the completed content in separate, clearly labelled Markdown tables that I can copy into the Word template.

### Check before delivery
Check that:
- every entry appears in the source passage and has its correct first-occurrence line number or table-row identifier;
- every line number has been counted from the printed anchors and checked visually against the source;
- every C1/C2 item from the supplied CEFR reference is included, and each CEFR label matches the item’s exact word form or same-part-of-speech lemma;
- title items, non-list words, derivatives, phrases, and proper nouns follow the stated rules;
- items are in source order, left-to-right on the same line, and are not repeated in later text sections;
- every POS label is permitted, every definition fits the context, and every required example has 8–12 words;
- the Word document has no empty template rows, missing entries, clipped rows, or poor table breaks.

If you cannot read an attached file, create the requested file type, check a CEFR level against the supplied reference, or verify the layout, say so before proceeding. Offer the closest useful alternative. Do not claim to have completed a check that you could not perform.

Ask one focused question only if an essential input is missing. Otherwise, proceed.
```

## Before you use the result with students

Check a sample of entries against the original passage, especially title words, first occurrences, line numbers, and specialised vocabulary. Confirm that the AI has used the CEFR reference correctly and that an item has not been repeated in a later text table.

If you requested a Word document, open it before use. Check that every section and table is present, Chinese characters display correctly, and no row is missing or cut off at a page break.

## If your AI assistant cannot make the file you want

Ask for the completed glossary as Markdown tables with the required columns. You can copy them into your own Word template and complete the final layout there.

## What you can change

You may change `[HONG KONG SENIOR-SECONDARY / DSE ENGLISH STUDENTS]`, the language variety, whether you attach a template, and the CEFR reference list. Keep the source-based line check, exact CEFR matching, source-order rule, one-entry-only rule, and final file check unchanged because they protect the glossary’s accuracy.
