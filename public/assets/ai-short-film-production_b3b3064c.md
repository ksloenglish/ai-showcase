# AI Short-Film Production

## What this makes

This prompt creates a **complete, ready-to-use production pack** for a short AI-generated film for a secondary-school English lesson. It includes character and location guides, a timed shot list, dialogue and sound notes, image/video prompts, and a final discussion question.

## What you need

- A short story idea or outline, together with the learner age or level and the intended classroom use.
- A clear description of the characters, their clothing changes, locations, plot, dialogue, and any rules that must not be broken.
- Any visual reference images or layout references that should guide the setting, character appearance, or composition.
- The target runtime, number of shots, aspect ratio, resolution, language variety, permitted on-screen text, and preferred music mood. You may leave a choice in brackets if you want the AI to suggest it.

## How to use it

1. Prepare the material listed above. If you have reference images, attach them with your story notes.
2. Open your chosen AI assistant and attach or paste the material.
3. Copy the whole prompt below. Change only the words in `[SQUARE BRACKETS]` if needed.
4. Send the prompt. Read through the result before using its prompts in an image, video, or audio generator.

## Copy-and-paste prompt

```text
You are helping me create a complete AI short-film production pack for [LEARNERS AND CLASSROOM CONTEXT].

### Materials
I have provided: [DESCRIBE THE STORY NOTES, CHARACTER DESCRIPTIONS, DIALOGUE, REFERENCE IMAGES, LOCATIONS, AND ANY EXISTING SCRIPT].
Use only information you can read from these materials. Do not invent, alter, or silently omit source content. Where a practical production detail is missing, use a clearly marked [SUGGESTED] detail rather than presenting it as a stated fact.

### Task
Turn the material into a production pack for a [TARGET RUNTIME]-second short film in [ASPECT RATIO] at [RESOLUTION], divided into approximately [NUMBER OF SHOTS] short shots. The film is intended to support [LEARNING PURPOSE, FOR EXAMPLE SPEAKING OR STORY DISCUSSION]. The story should have a clear beginning, development, and ending. End with [A DISCUSSION QUESTION / A REFLECTIVE MOMENT / OTHER ENDING].

This is a planning and prompt-writing task. Do not claim that you have generated, rendered, or checked a finished video, image, audio track, or document unless you can actually do so. If I later ask you to create assets, work from this approved production pack.

### Requirements
1. Create a concise project overview with the story premise, intended audience, learning purpose, total target runtime, target aspect ratio, resolution, permitted on-screen text, and selected language variety. Use [BRITISH ENGLISH] unless I specify otherwise.
2. Establish a visual-and-sound profile using descriptive qualities such as lighting, colour, animation or film technique, camera energy, and mood. Do not name or imitate a living artist, a named studio, or a copyrighted franchise. Describe the desired look in your own words instead.
3. Create a continuity guide for every recurring character. Include appearance, age-appropriate clothing, hairstyle, voice qualities, emotional role, and each wardrobe state. State all hard rules clearly, including any face, camera-angle, prop, or costume restrictions. For each character, provide a reusable character-sheet prompt designed to establish consistent references before scene generation.
4. Create an empty location-plate prompt for every setting. Specify the environment, fixed furnishings, camera viewpoint, lighting, screen layout, and all prohibited details. Each location plate must contain no people, vehicles, logos, watermarks, or unwanted text unless I have expressly requested them.
5. Provide a timed, numbered shot list in a Markdown table. For every shot, include: shot ID; title; duration; characters and wardrobe state; location/reference assets; framing and camera movement; action and emotion; exact dialogue with speaker and time cue where relevant; ambient sound; music direction; on-screen text; and continuity notes. Number the shots sequentially. Calculate and show the total duration from the shot table, and flag any difference from the target runtime.
6. Keep dialogue short, natural, age-appropriate, and clearly audible. Separate dialogue, diegetic sound, music, silence, and voice-over notes. Ensure that dialogue is louder and clearer than environmental sound and background music.
7. Write one production-ready prompt for each character sheet, location plate, and shot. Each prompt must repeat the agreed visual description where needed, specify the required reference assets, and include negative constraints that protect continuity. Do not include invisible internal settings, private links, local paths, or tool-specific action names.
8. Include a separate instrumental background-music prompt only if music is requested. It must state the mood, instrumentation, timing, dialogue ducking, and a natural ending. Do not include vocals unless I ask for them.
9. Use no captions, narration, logos, watermarks, or on-screen text other than [LIST OF APPROVED TEXT CARDS]. Do not add extra text merely to explain the story.
10. If I provide reference images, state exactly where they should be reused to maintain character or location continuity. If no reference images are provided, label the required reference assets that should be created first.

### Output
Provide one clearly organised Markdown production pack with these sections in this order:

1. **Project overview**
2. **Visual and sound profile**
3. **Character continuity guide and character-sheet prompts**
4. **Location guide and empty location-plate prompts**
5. **Timed shot list**
6. **Individual shot-generation prompts**
7. **Background-music prompt** (only if requested)
8. **Final production checklist**

Use [BRITISH ENGLISH / OTHER REQUIRED VARIETY]. Keep all dialogue in the requested language. Do not produce the final video itself unless I explicitly ask for video generation after approving the production pack.

### Check before delivery
Check that:
- the pack uses the story, characters, dialogue, locations, and reference material I supplied, without adding unsupported plot facts;
- every shot has a sequential ID, duration, camera direction, action, sound note, and continuity note, and the calculated total duration is shown;
- character identity, wardrobe state, hairstyle, props, location layout, screen direction, and all hard staging rules remain consistent from shot to shot;
- every spoken line is attributed to the correct character, fits its stated time window, uses [BRITISH ENGLISH / OTHER REQUIRED VARIETY], and can be heard clearly above music and ambient sound;
- every character and location prompt contains the necessary continuity constraints and does not name or imitate a living artist, named studio, or copyrighted franchise;
- no unapproved caption, narration, logo, watermark, or on-screen text has been added; and
- the final shot and discussion question match the intended classroom purpose.

If you cannot read an attached file, create the requested file type, run a required check, or verify a layout, say so before proceeding. Offer the closest useful fallback. Do not claim to have completed a capability you do not have.

Ask one focused question only if an essential input is missing. Otherwise, proceed.
```

## Before you use the result with students

- Check that the story, character relationships, setting, and dialogue still match the material you supplied.
- Check the total duration, shot order, dialogue timing, wardrobe states, and all restrictions such as “face not shown” or “no mirrors”.
- Read each line aloud to check that it is natural, age-appropriate, and suitable for your learners.
- If you generate a video from the pack, watch the completed film before class. Check that speech is intelligible, visual continuity has held, and no extra text or unwanted imagery has appeared.

## If your AI assistant cannot make the file you want

Ask it for the production pack as an editable Markdown table and plain text. You can paste the prompts into the image, video, music, or audio tools available to you. If it cannot analyse an uploaded image, describe the important details in your own words and use that description as the reference.

## What you can change

You may safely change the story, year group, language variety, runtime, number of shots, aspect ratio, resolution, setting, character names, dialogue, visual description, reference images, music mood, and ending question. Keep the numbered shot structure, continuity guide, audio notes, permitted-text rule, and final checklist because they protect the quality and classroom usefulness of the film.
